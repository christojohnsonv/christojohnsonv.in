01 / About

Building the backend behind the product.

My work is primarily about making backend systems predictable: clear interfaces, sensible data models, reliable background processing and infrastructure that can be understood and operated.

I'm an Associate Technical Lead and backend engineer working primarily with Python and increasingly Go. Over the course of my career, I've worked on API platforms, financial-data aggregation, network-management systems, analytics pipelines and production infrastructure.

I enjoy problems that sit below the feature layer: service boundaries, database behaviour, concurrency, data movement, performance and operational reliability. My approach is to keep systems understandable first, then make them faster and more scalable where the workload requires it.
