01 / About

Backend by trade. Systems by instinct.

From API contracts to infrastructure, I care about how the whole system behaves.

I'm a backend engineer and Associate Technical Lead with 7+ years of experience building backend systems and APIs. My work spans application architecture, API design, databases, asynchronous processing, distributed systems, cloud infrastructure and production operations.

I've worked on systems involving Django/DRF, FastAPI, PostgreSQL, Redis, Kafka, Celery, ClickHouse, Linux, Docker, AWS and related infrastructure. I enjoy understanding systems deeply, especially where application code meets databases, infrastructure and production behavior.

My career has gradually moved from implementing individual backend features toward designing systems, improving performance, making architectural decisions and helping other engineers deliver reliably.

Design for claritySimple interfaces and understandable service boundaries.
Measure before tuningUse query plans and analysis to find real bottlenecks.
Treat data seriouslyCorrect models, predictable queries and safe migrations.
